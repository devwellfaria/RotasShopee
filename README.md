# Rotas Shopee

App web (PWA) para registrar rotas de entrega: cidade, pacotes, paradas, valor da rota e combustível gasto no dia.

- Resumo da semana (segunda a domingo) ou do mês
- Gráfico de valor por dia, com maior e menor valor destacados
- Folga, edição e exclusão de rotas
- Funciona offline e pode ser instalado na tela inicial do Android

Os dados ficam salvos só no aparelho (localStorage). Não há servidor nem sincronização.

## Como usar

1. Ative o GitHub Pages: Settings > Pages > Deploy from a branch > `main` / `(root)`.
2. Abra o link `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/` no Chrome do celular.
3. Menu do Chrome > Instalar app (ou Adicionar à tela inicial).
